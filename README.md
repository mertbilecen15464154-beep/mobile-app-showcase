# 📱 Cross-Platform Mobile Application Development Showcase

Çoklu platform (iOS & Android) mobil uygulama arayüzleri, bileşen şablonları ve kullanıcı deneyimi (UX) prototiplerini içeren proje sergisi.

---

## ✨ Öne Çıkan Özellikler

- 📲 **Çapraz Platform Uyumlu UI:** Mobil cihaz çözünürlüklerine tam uyumlu arayüz bileşenleri.
- ⚡ **Performans Odaklı Yapı:** Akıcı dokunmatik etkileşimler ve mikro animasyonlar.
- 🧩 **Modüler Mimari:** Reusable (yeniden kullanılabilir) component ve görünüm yapıları.

---

## 🛠️ Kullanılan Teknolojiler

- **UI Framework / Styling:** HTML5 / Mobile Web CSS / JavaScript
- **Platform:** iOS & Android Web App Templates
